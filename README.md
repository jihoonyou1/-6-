# -6-

- 한경대학교 IoT프로그래밍 기말 과제 6조 github
- 사용 방법 - 라즈베리파이 터미널에서 git clone https://github/com/jihoonyou1/-6-
1. 프로그램 개요
- DHT22 온습도 센서를 이용해 얻은 온습도 데이터를 이용해 라즈베리파이 내 FPGA와 Touch Screen을 이용하여 제어하는 프로그램입니다.

2. 폴더 설명
- DHTfile : DHT22를 테스트하기 위한 코드들의 폴더입니다
- Milestone_1 : 프로젝트를 하면서 개발 단계 마다의 중간 보고서와 최종 보고서의 폴더입니다.
- Relay_file : 5v 릴레이 모듈을 테스트하기 위한 코드들의 폴더입니다.
- fpga : 최종적으로 저희가 완성한 파일들의 폴더입니다.
